    ℹ️ How to use this tool & CSV format guide
    

      CSV File Format

      Your CSV must have a header row with at least two columns: Function and IR Command.

      Column names are flexible — the tool will detect them automatically.



      Example CSV (Key / Function header also supported):
      
Function,IR Command
"Power","""C:\Program Files (x86)\RedRat\WinCommManager\RRCmd\RRCmd.exe"" ir ""MyDevice"" ""Power"""
"Vol+","""C:\Program Files (x86)\RedRat\WinCommManager\RRCmd\RRCmd.exe"" ir ""MyDevice"" ""Vol+"""


      ME5 XML format used: The tool generates real ME5 <Fld> elements with <Act name="RunApp" param="..."> — the exact format ME5 uses natively.



      Inject Mode: Upload your existing ME5 pageset XML and a CSV. The tool finds the target page, then for each CSV row either:

      • Matches an existing <Fld> by its label attribute (case-insensitive) and adds/replaces the RunApp action

      • Or appends a new <Fld> to the page



      Generate Mode: Creates a brand-new <Page> XML block from your CSV. Paste the <Page>...</Page> block into your pageset XML (inside the <Document> element).



      Where to find the pageset XML:

      In Windows Explorer, navigate to:
      
C:\Users\Public\Documents\ME5Data\Users\[username]\Portal\[PagesetName]\Documents\

      Upload the .xml file from that folder. After the tool downloads the modified XML, copy it back into that same folder (overwrite the original). Restart / reload the pageset in Mind Express 5.


      Note on .ME5 files: ME5 export files are password-encrypted and cannot be opened by this tool. Use the live XML folder instead as described above.

      Quote handling: The RRCmd CSVs use triple-quoting (Excel style). This is handled automatically — the parsed command will contain the correct embedded quotes that ME5 requires.
